# Реестр веток heli-bot

Снимок 07.11.2026, main `08ef21e`. Всего 76 веток кроме main. Только опись: **ни одна ветка не удалена**.

Как считалось: «впереди / позади» по `git rev-list --left-right`. Для веток, влитых squash-мержем, «впереди» не ноль, хотя содержимое в main; поэтому проверено ещё, совпадает ли голова ветки с головой влитого PR (то есть после мержа в ветку ничего не дописали). Скрипт: `docs/branch-inventory.sh` (запускать из корня клона после `git fetch origin`), сырые данные: `docs/branch-inventory.tsv`.
