## Маскот Heli (`mascot/`)

Основа — маскот с getheli.ru. Добавлены хвостовая балка с винтом, лампа-индикатор на втулке винта и мимика под состояния агента.

| Файл | Назначение |
|---|---|
| `heli-idle.svg` | Ожидание |
| `heli-thinking.svg` | Думает (точки-мысли, оранжевая лампа, медленный винт) |
| `heli-working.svg` | Работает: мягкая анимация — винт крутится (0,4 с), хвостовой винт (0,8 с), плавное покачивание на 3,5 px (1,6 с), линии скорости |
| `heli-working.lottie.json` | То же в Lottie (188×188, 30 fps, 48 кадров, цикл) для lottie-web / lottie-react / dotLottie |
| `heli-done.svg` | Готово (улыбка, бейдж с галочкой) |
| `*-static.svg` | Те же состояния без анимации (для PNG/ICO и мест, где SMIL не работает) |
| `avatar-*.svg` | Круглый аватар агента на мятном фоне, `avatar-idle-dark.svg` — для тёмной темы |
| `app-icon-macos.svg` | Иконка приложения 1024×1024 с полями по сетке macOS |
| `app-icon-windows.svg` | Иконка 1024×1024 без полей (для `.ico` / Tauri `icons/`) |
| `app-icon-light.svg`, `app-icon-dark.svg` | Альтернативные фоны |

Для Tauri: `npx tauri icon design/mascot/app-icon-windows.svg` после конвертации в PNG 1024×1024.

## Пауза, стоп и цена задачи (`flows/pause-stop-price.md`)
