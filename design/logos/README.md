# Логотипы подключений

Все знаки в SVG и взяты с официальных ресурсов правообладателей. Из файлов убраны скрипты и метаданные, форма и цвета не менялись.

| Файл | Источник | Что это |
|---|---|---|
| `1c.svg` | Логотип фирмы «1С» (Wikimedia Commons, `1C_Company_logo.svg`, копия официального знака) | Знак «1С» |
| `bitrix24.svg` | bitrix24.ru, `/favicon.svg` | Знак приложения «24» |
| `telegram.svg` | telegram.org, `/img/t_logo.svg` | Знак Telegram |
| `yandex-360.svg` | 360.yandex.ru: знак из официального логотипа «Яндекс 360» в коде сайта (компонент логотипа, viewBox 246×40, знак 40×40) | Оранжевый круг «360» с радиальным градиентом `#FF9A6F → #FF6427 → #EB581E` |
| `amo-wordmark-white.svg` | amocrm.ru, страница входа: кнопка «Войти через amo» | Белый словесный знак «amo», как в оригинале |
| `amocrm.svg` | Тот же знак «amo» на чёрной квадратной плашке 48×48 с радиусом 12 | Для плиток и списков: так amoCRM сам ставит знак на свою кнопку входа (белый «amo» на `#000`) |

## Использование в интерфейсе

- Знак лежит на белой плашке 44 px с рамкой (в списке ботов 26 px), поэтому одинаково читается в светлой и тёмной темах.
- Для amoCRM используется `amocrm.svg` на всю плашку. Это знак «amo», а не «K» Kommo.
- Все знаки — товарные знаки их владельцев. Они нужны только для обозначения интеграции, менять форму и цвет нельзя.

## Перед релизом

Публичных брендбуков с файлами для скачивания у Яндекс 360 и amoCRM нет: страницы `amocrm.ru/press` и `/brand` отвечают 404, а на странице правил Яндекса лежит только общий логотип «Яндекс». Поэтому знаки взяты из кода официальных сайтов. Если появится партнёрский пресс-кит, файлы стоит сверить с ним, имена файлов менять не нужно.
