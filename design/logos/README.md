# Логотипы подключений

| Файл | Источник | Формат |
|---|---|---|
| `1c.svg` | Логотип фирмы «1С» (Wikimedia Commons, `1C_Company_logo.svg`), очищен от метаданных Inkscape | SVG |
| `bitrix24.svg` | Знак приложения с bitrix24.ru (`/favicon.svg`) | SVG |
| `telegram.svg` | telegram.org (`/img/t_logo.svg`) | SVG |
| `yandex-360.png` | Фавикон 360.yandex.ru, 96×96 | PNG |
| `amocrm.png` | Фавикон amocrm.ru, 96×96 — сейчас это знак Kommo «K» | PNG |

Официальные SVG Яндекс 360 и amoCRM в открытом доступе получить не удалось: перед релизом их нужно взять из брендбуков (Яндекс 360 — пресс-кит Яндекса, amoCRM/Kommo — по запросу в партнёрской программе) и заменить PNG.

Знаки — товарные знаки их владельцев; используются только для обозначения интеграции, без изменения формы и цвета. В интерфейсе знак лежит на белой плашке 44 px (в списке ботов — 26 px) с рамкой, чтобы одинаково читаться в светлой и тёмной темах.
